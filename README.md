# Task Management

## Prerequisites

Install the following tools before setting up the project:

- [Node.js](https://nodejs.org/) with npm
- [Python](https://www.python.org/) 3.10 or newer

## Install Dependencies

The frontend and backend are separate projects, so install their dependencies independently.

### Frontend

From the repository root, run:

```powershell
cd frontend
npm ci
```

### Backend

From the repository root, create a virtual environment and install the Python dependencies:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install python-multipart
```

The backend requires a `backend/.env` file with these values:

```dotenv
DATABASE_URL=your_database_connection_url
SECRET_KEY=your_jwt_secret_key
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
PASSWORD_RESET_OTP_SECRET=use_a_separate_random_secret
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=your_smtp_username
SMTP_PASSWORD=your_smtp_password
SMTP_FROM_EMAIL=no-reply@example.com
SMTP_USE_TLS=true
SMTP_USE_SSL=false
AI_API_KEY=your_ai_provider_api_key
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=your_openai_compatible_model
AI_TIMEOUT_SECONDS=45
```

`ACCESS_TOKEN_EXPIRE_MINUTES` is optional and defaults to `30`.
`PASSWORD_RESET_OTP_SECRET` should be a separate random secret; when omitted,
`SECRET_KEY` is used. Configure either SMTP TLS (typically port `587`) or SMTP
SSL (typically port `465`) so password reset codes can be delivered.

## Configure the AI API

The assistant and AI-enhanced project report use an OpenAI-compatible Chat
Completions endpoint. The standard task CSV export is generated by the backend
and does not consume AI tokens.

### 1. Choose a compatible provider

Create an API key with a provider that supports this request shape:

```text
POST {AI_BASE_URL}/chat/completions
Authorization: Bearer {AI_API_KEY}
```

Example configurations:

| Provider | `AI_BASE_URL` | Example `AI_MODEL` |
| --- | --- | --- |
| [OpenAI](https://platform.openai.com/api-keys) | `https://api.openai.com/v1` | `gpt-5-mini` |
| [GroqCloud](https://console.groq.com/keys) | `https://api.groq.com/openai/v1` | `openai/gpt-oss-20b` |
| [OpenRouter](https://openrouter.ai/settings/keys) | `https://openrouter.ai/api/v1` | `openrouter/free` |
| [Local Ollama](https://ollama.com/download) | `http://localhost:11434/v1` | A locally installed model, such as `qwen3:8b` |

Model availability and pricing can change. Use the exact model ID shown in
your provider account. A ChatGPT Plus or Pro subscription does not include
OpenAI API credits; API billing is configured separately on the OpenAI
Platform.

### 2. Add the credentials

Update the AI values in `backend/.env`. For example, with OpenAI:

```dotenv
AI_API_KEY=your_secret_api_key
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-5-mini
AI_TIMEOUT_SECONDS=45
```

For GroqCloud, the same section would look like:

```dotenv
AI_API_KEY=your_groq_api_key
AI_BASE_URL=https://api.groq.com/openai/v1
AI_MODEL=openai/gpt-oss-20b
AI_TIMEOUT_SECONDS=45
```

Keep `AI_API_KEY` in `backend/.env`. Never put it in a `VITE_` variable, send
it to the frontend, include it in screenshots, or commit it to Git.

### 3. Restart and test

Restart the backend after changing the environment values:

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
python -m uvicorn src.main:app --reload
```

Then test these flows:

1. Open the dashboard, select **Ask AI**, and ask about an accessible task or project.
2. Ask the chatbot to generate or export a CSV. Select a scope and use **Download CSV**.
3. Open a project and use **AI CSV report** to generate a report with an AI summary and task insights.

The first and third flows require a configured AI provider. The chatbot CSV
download is generated from authorized database records and does not call the
provider.

### Troubleshooting

| Symptom | Check |
| --- | --- |
| `AI is not configured on the server` | Confirm `AI_API_KEY` and `AI_MODEL` exist in `backend/.env`, then restart the backend. |
| `The AI provider request failed` | Verify the API key, base URL, model ID, provider quota, and billing status. |
| `The AI provider timed out` | Increase `AI_TIMEOUT_SECONDS` or select a faster model. |
| CSV report returns invalid report data | Use a model that reliably follows JSON instructions. |
| Chatbot CSV has no rows | Confirm the signed-in user can access projects containing tasks. |

See [AI Integration Flow](docs/AI_INTEGRATION.md) for the architecture, data
boundaries, API contracts, and end-to-end request flows.

## Start the Frontend

Open a terminal at the repository root and run:

```powershell
cd frontend
npm run dev
```

Vite prints the local frontend URL in the terminal, typically `http://localhost:5173`.

## Start the Backend

Open a second terminal at the repository root and run:

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
python -m uvicorn src.main:app --reload
```

The API is available at `http://localhost:8000`, with interactive documentation at `http://localhost:8000/docs`.
